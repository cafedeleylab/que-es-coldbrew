# Cold brew — Café de Ley

Landing con la última versión del diseño, los textos y las animaciones de scroll.
Todos los archivos están sueltos en esta carpeta. No requiere instalación ni compilación.

## Subir a GitHub

1. Abre o crea el repositorio donde quieras guardar la página.
2. Selecciona **Add file → Upload files**.
3. Arrastra todos los archivos de esta carpeta al repositorio, sin meterlos dentro de otra carpeta. `index.html` debe quedar en la raíz.
4. Guarda los cambios con **Commit changes**.

## Publicar con GitHub Pages

1. En el repositorio, abre **Settings → Pages**.
2. En **Source**, selecciona **Deploy from a branch**.
3. Selecciona la rama donde subiste los archivos (normalmente `main`) y la carpeta **/(root)**.
4. Pulsa **Save**. La URL de la página aparecerá en esa misma pantalla cuando termine la publicación.

Las rutas son relativas: funcionan también cuando GitHub Pages publica dentro de `/nombre-del-repositorio/`.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Archivos

- `index.html`: estructura y textos.
- `styles.css`: diseño, tamaños y distribución.
- `script.js`: animaciones y comportamiento del scroll.
- `idiomas.js`: traducción completa entre español e inglés mediante el botón superior izquierdo. La elección se guarda en el navegador.
- `cafe-molido.jpg`, `grano.png`, `cold-brew.png`, `logo-cafe-de-ley.png`: imágenes.
- `instrument-serif.ttf`, `instrument-sans.ttf`: tipografías locales.
- `licencia-instrument-serif.txt`, `licencia-instrument-sans.txt`: licencias de las tipografías; conservar con los archivos.

Puedes abrir `index.html` en tu navegador para ver la página. Conserva todos los archivos juntos y sus nombres originales.
